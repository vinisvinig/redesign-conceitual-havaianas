# Havaianas · Cada cor guarda uma história (redesign conceitual)

Home de um redesign conceitual e não oficial da Havaianas: um leque de chinelos em 3D, e cada cor conta um capítulo da história da marca enquanto o chinelo desce com o scroll. Feito com HTML, CSS, Three.js e GSAP ScrollTrigger.

Abra o `index.html` ou acesse pelo GitHub Pages. Arquivo único, sem dependências externas.

Fontes dos fatos: havaianas-store.com/en/history · ipe.org.br · historiadomundo.com.br · fashionunited.es
